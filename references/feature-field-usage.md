# feature 字段使用规范

> **核心原则**: `feature` 字段是系统运维扩展字段，**禁止**在业务代码中读写。

## 规则

- `feature` 字段（JSONB 类型）仅供 DBA 或运维人员手工查询使用
- 业务代码不得将 `feature` 用于业务逻辑判断
- 不得在业务 Service、Repository、Adapter 中读取或写入 `feature`

## 用途示例

- 运维手动更新表特征标记（如「该表已开启某实验特性」）
- 排查问题时查询表级别的实验标记

---
**执行检查点**: 搜索代码中是否有 `feature` 字段的业务读写逻辑。
